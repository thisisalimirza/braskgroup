What this actually is

I run a small agency, Brask Studio, building sites for healthcare companies and early-stage startups. That work pays for the experiments — apps, tools, a newsletter — that I build for myself.

Some of those experiments turn into real products with real users. When they do, they usually end up as case studies for Studio, which brings in the next client. It’s one system, not four separate companies pretending to be a portfolio.

I’ve done this before. I ran an agency, JANUS, before medical school. Brask Studio is that same model, run better, funding things that actually interest me this time. JANUS did everything from email marketing to full-stack web development — SEO, analytics, Shopify — before settling on motion design launch videos. Brask Studio is the hyper-focused version of that: clean, fast marketing sites.
